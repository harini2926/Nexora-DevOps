Features

Everything you need to go from an idea to a playable scene, in one workspace.

AI Game Creator

Describe your game in plain language. Nexora generates scenes, scripts and assets you can refine.

Visual Editor

Drag, drop and transform objects on a real 2D scene canvas. Pan, zoom and inspect every property.

Live Preview

Hit Play and see your game run immediately, with keyboard input and physics applied in real time.

Python Scripting

Write gameplay logic in Python. Attach scripts to any object and iterate without leaving the engine.

Scene Save & Load

Every scene is stored as readable JSON so you can version, share and diff your work.

Cross-platform Runtime

Built on C++, OpenGL and Dear ImGui — runs the same on Windows, macOS and Linux.
