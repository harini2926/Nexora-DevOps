Documentation

Get up to speed with Nexora in a few minutes.

1. Create an account

Click Register to make your free account. Login with Google or email.

2. Start a project

From the dashboard, click Create New Project. Pick a template (2D, 3D, Visual Novel or AI Interactive) and give it a name.

3. Edit the scene

Drag objects on the canvas. Use the Inspector to change position, rotation and scale. Middle-mouse pans, scroll zooms.

4. Write gameplay scripts

Every scene folder has a Scripts/ directory. Nexora runs Python files attached to objects.

import nexora

class PlayerController(nexora.Component):
    def start(self):
        self.speed = 250

    def update(self, dt):
        axis = nexora.input.axis("Horizontal")
        self.transform.position.x += axis * self.speed * dt

5. Save and share

Hit Save Scene. Your scene is written to Scenes/Main.scene as JSON. Commit it, share it, diff it.
