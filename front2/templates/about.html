About Nexora

Nexora is an experimental AI-powered game engine built by a small team of developers and designers. Our goal is simple: make it possible to go from a text idea to a playable game without switching tools.

The engine is written in C++ with Dear ImGui and OpenGL, with a Python scripting layer for gameplay logic. Everything is saved as plain JSON so your work is portable and diffable.
